# 李璐的个人作品集网站

只有一个文件 `index.html`，不需要安装任何东西，双击就能在浏览器里打开预览。

## 改内容
用 Cursor 或任何文本编辑器打开 `index.html`，搜索 `CONFIG`，只改那一段里引号中的文字：
名字、自我介绍、项目、文章、邮箱 / 微信 / 小红书。

## 放图片（放进去自动替换占位图，文件名要一致）
- `assets/avatar.png`：3D 头像（透明背景）
- `assets/marquee/1.png` ~ `6.png`：滚动带截图（横图，大约 16:10）
- `assets/projects/encore/1.png 2.png 3.png`：安可 Encore 的三张图
- `assets/projects/pet/1.png 2.png 3.png`：宠伴
- `assets/resume.pdf`：简历

图片不是 .png 的话，用 Mac「预览」打开 → 文件 → 导出 → 格式选 PNG。
